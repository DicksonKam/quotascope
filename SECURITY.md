# Security and support

This is a local application. Keep it bound to loopback; do not reverse-proxy it onto a network. Host/Origin checks and a same-origin request token protect mutation routes, but any software already running as your user may access your local data.

Report suspected security issues privately through GitHub's private vulnerability reporting when enabled by the repository owner. If that channel is unavailable, request a private contact without posting sensitive details publicly. Do not include tokens, identity keys, databases, source logs, personal exports or screenshots in an issue.

For ordinary bugs, include the OS, architecture, Node and CLI versions, the operation that failed, and a redacted doctor summary. Reproduce with synthetic fixtures if possible. There is no warranty or claim of complete coverage, billing accuracy, or uninterrupted monitoring.
